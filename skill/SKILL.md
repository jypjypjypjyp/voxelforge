# 体素建模（voxelforge）

像雕刻一样建模：**粗坯 → 细雕 → 精修 → critic 评审闭环**，每阶段有出口校验，critic PASS 才交付（草稿/微调可走**快速模式**省去独立评审，见阶段 4）。

## 快速开始

```bash
npm i -g voxelforge      # 首次安装（npm 正式包，Node ≥20）；之后升级同命令
VF=voxelforge            # 全局安装后直接用命令名；免安装可改用 npx voxelforge（每次解析稍慢）
# 本地仓库开发调试时：先 npm run build，再 VF="node <仓库路径>/dist/cli.js"
$VF tools                                  # 列出全部 19 个工具
$VF new /tmp/model.voxel.json --size 64    # 新建 64³ 项目（已存在加 --force）
$VF tool /tmp/model.voxel.json box '{"x0":8,"y0":0,"z0":8,"x1":55,"y1":7,"z1":55,"color":"#9aa0a6","hollow":true,"mirror":["x"]}'
$VF tool /tmp/model.voxel.json check
```

工具参数是 **JSON 对象**，颜色一律 `#RRGGBB`，引擎自动分配调色板。

## 19 工具速查（`$VF tools` 可随时列出）

| 命令 | 用途 | 要点 |
|---|---|---|
| `create_project` | 新建 | `{size:[64,64,64]}`；已存在须 `force:true` |
| `info` | 概览 | 尺寸/体素数/调色板/包围盒/每色计数 |
| `box` / `sphere` / `cylinder` / `line` | 几何体 | 均支持 `hollow:true`（只留壳）与 `mirror:["x"\|"y"\|"z"]`（对称一次成型） |
| `set` / `unset` | 单点 | |
| `paint` | 换色 | `region` 省略=全网格；`from` 省略=区域内全部 |
| `erase` / `translate` | 擦除/平移 | erase 的 region 可传 `"all"` |
| `undo` | 撤销 | 内存快照栈 20 步 |
| `sample` | 读单点 | 校验某处颜色 |
| `slice_ascii` | 层字符画 | `{axis:"y",index:3}`——空间定位最便宜的手段 |
| `check` | 自诊断 | 悬空/连通分量/对称差/每轴 occupancy 剖面 |
| `script` | 批量生成 | vm 沙箱跑 JS（见下） |
| `export` | 导出 | `{format:"glb"}` 或 `"vox"` |
| `render_png` | 渲染目检 | `{views:"multi", path:"/abs/out.png"}` 三视图合一；`highlight:[x0,y0,z0,x1,y1,z1]` 描红；输出路径字段是 **`path`** |
| `sdf_mesh` | 体素→平滑网格 | `{resolution:32}`（立方最大轴边长,默认=体素size）；`color` 平涂单色/缺省采样最近体素色；`smooth` 0-8；`texture:true` 导出调色板图集贴图+UV 的 GLB（NEAREST 采样零渗色，替代顶点色）；出 GLB（结构闸门通过） |

## 建模工作流（仿雕刻：粗坯 → 细雕 → 精修 → critic 评审闭环）

像雕刻一样工作：先用**大几何**定比例，再在坯上**增减**成型，最后精修，并进入 **critic 评审闭环**——独立子代理当评审，评审提出问题、主代理解决问题，1-3 轮直到达成最终效果。每个雕刻阶段有出口校验，critic PASS 才交付；只有草稿/微调走**快速模式**（省去独立评审，见阶段 4）。

### 阶段 1｜粗坯（blocking）
- 只用**大的基础几何**（大方块、大圆柱、球）摆出轮廓与比例——此阶段只求"形与比例对"，**禁止写细节**（比例未定的细节全是返工）
- 对称体从第一步就上 `mirror`
- 出口校验：`check` + `render_png`（iso 单视图即可）确认比例；比例错了在这里返工最便宜

### 阶段 2｜细雕（carving）
- 在粗坯上**增减**：`erase` 挖门窗/掏空/削角，box/cylinder 加附属（檐、翼、烟囱、喷口），`line` 勾棱
- 每完成一个部件 `check` 一次；`slice_ascii` 抽查部件关键层

### 阶段 3｜精修（detail）
- `paint` 分区配色、`set` 点缀小体素（多数模型 < 20 色）
- 出口校验：`check` 各项**可解释**（floating/symmetry 见语义坑——合法悬挑不必归零）

### 阶段 4｜critic 评审闭环（默认必做；草稿/微调可走快速模式）
- critic = **独立子代理评审**：用你环境里的子代理/后台任务机制派一个 fresh-context 评审员（不带你的过程叙述），简报只给四样：模型文件路径、VF 命令（如 `voxelforge`）、用户需求原文、**审查通道**（图片/文本，见下《审查通道》）
- critic **按自己的通道取证**（图片通道：`render_png` 后 `read_image` 真看图；文本通道：收齐《审查通道》的五样证据），对照需求找问题；**只读不改**；输出 `PASS` 或编号清单（每条：region + 严重度 + 建议）
- **闭环**：critic 提出问题清单 → 主代理逐条修复 → 重渲 → 再派新 critic 复审；**1-3 轮循环，直到 critic 输出 PASS（即达成最终效果）**
- 防空转守卫：若连续两轮问题不收敛（同类问题反复出现），停止循环，把分歧点原样汇报给用户裁决——不无限循环，也不带分歧交付
- ⚠️ critic 结果回传后必须**汇总最终汇报再结束回合**——禁止"派完评审就挂起等待"
- 环境不支持子代理时：降级为"换视角自审"——对照 render/check/slice 清单逐项过一遍，假装第一次看

#### 快速模式（省去独立评审）

- **何时用**：用户说"快速/先出个草稿/不用评审"，或只是局部微调已有模型。**什么时候不用**：交付级成品、多部件大模型、要导贴图或平滑网格——这些走完整闭环。
- **省掉什么**：只省"派独立 critic"这一步。三阶段出口校验、`check`、交付前 `render_png` 目检（按《审查通道》）一样不能少。
- **自审一轮替代**：自己按 critic 的清单格式过一遍（region + 严重度），发现的问题当场修，不另起评审轮次。
- **必须明说**：汇报末尾写「本轮快速模式：未做独立评审」——不让"省了评审"被读成"评审通过"。
- **随时升级**：自审问题 ≥3 处、同类问题修两轮不收敛、或用户不满意时，停止快进，补完整评审闭环再交付。

### 阶段 5｜交付
- `render_png {views:"multi"}` 最终目检：按《审查通道》执行——有视觉就 `read_image` 真看图；没有就在汇报里写明「本轮未做图片审查」
- `export {format:"glb"}`（自带结构闸门摘要）

**纪律**：粗坯期禁写细节；结构闸门通过 ≠ 视觉正确——宣称完成前必须 `render_png` 且按《审查通道》真看图（无视觉则明写未做图片审查）；critic 意见与你的判断冲突时，先重渲核实再反驳。

## 审查通道（图片优先，文本回退）

评审与目检只有这两条通道，**按评审者能否真正看到图分流**：

- **判据**：主代理派评审员时在简报里写明 `审查通道：图片` 或 `审查通道：文本`；未写明时评审员自己试一次 `read_image`——能看到图走图片通道，读不到图立即回退文本通道，不重试、不猜。
- **图片通道（优先）**：`render_png {views:"multi"}` 一次出 iso/front/side 合成图 → `read_image` 打开 PNG **靠眼睛找问题** → 用 `highlight:[x0,y0,z0,x1,y1,z1]` 描红框，把问题区域坐标写进评审清单。拿到 PNG 路径不算审过。
- **文本通道（回退）**：按顺序收齐五样证据再下结论——`info`（尺寸/体素数/调色板/包围盒/每色计数）→ `check`（悬空/连通分量/对称差/每轴 occupancy 剖面）→ `slice_ascii` **逐关键层**（底面、门窗层、屋顶层……，不是只看一层）→ `sample`（抽查点位颜色）→ 数值闸门（`export glb` / `sdf_mesh` 返回的 tris/verts/bbox/体积，并与体素体积对比，判薄特征是否丢失）。
- **明说的取舍**：文本通道查得出结构错、比例错、颜色错、薄特征丢失；**查不出观感丑、风格不像**。所以走文本通道时汇报里必须写明「本轮未做图片审查」——不能让"没看"被读成"看过了没问题"。
- **两边能力不同时**：有视觉的一方负责看图，并把**看到的问题连同 region** 写成文字交给另一方；不能看图的一方只在自己的通道上复核结构，不得凭描述臆断画面。

## script() 批量生成

重复结构/数学形状用脚本一次成型（比逐个工具调用省轮次）：

```bash
$VF tool model.voxel.json script '{"code":"for (let i=0;i<10;i++) box(i*6,0,0,i*6+2,5,2,\"#8B4513\")"}'
```

- 沙箱 API：`box/sphere/cylinder/line/set/unset/paint/erase/translate/palette(hex)/size/log`
- 同步代码，默认 5s 超时；任何错误**自动回滚**到执行前
- ⚠️ `box/sphere/cylinder/line` 的区域要求**完全在界内**，越界即报错回滚

## 语义坑（必读，基线实测的试错点）

- region 六元组 `[x0,y0,z0,x1,y1,z1]` **含两端**（0..7 = 8 格）；min>max 自动纠正
- 朝向约定：**z 小的一侧 = front 视图正向**（"南墙"= min-z 侧）；x 左右、y 上下
- `check` 的 `floating`：正下方+四侧下方共 5 位全空且 y>0 才计——空心房间顶板、平顶出檐**天然大量 floating，属正常形态**，不是错误
- `symmetry.y` 豁免贴地层（y=0）——接地建筑 y 向不对称是正常的；看 x/z 的对称差
- 渲染光照下浅色偏灰是着色效果，非建模问题
- `box/sphere/cylinder/line`：越界区域**静默裁剪**（CLI 语义）；script 沙箱内则**严格报错**
- `translate/paint/erase`：区域越界静默裁剪；translate 目标出界/被占的体素被丢弃
- 调色板上限 **255 色**；`paint` 的 `from` 色必须已存在（防幻影）
- `mirror` 映射 `v → size-1-v`；每次放置自动复制镜像位，无需手摆两边
- ⚠️ 工具 JSON 字段与 CLI 旗标不同名：`tool` 子命令里输出路径是 **`path`**（`out` 是 `render` 子命令的旗标，写在 JSON 里会被忽略）
- `script` 沙箱参数形态：`box/set` 收标量坐标，`erase/paint/translate` 收 region **数组**——传错会报错自动回滚
- 坐标/圆心须为**整数**；奇数宽物体放偶数网格时，模型自轴与 mirror 轴（`size/2-0.5`）差半格 → `check` 的 symmetry 出现系统性伪影（让 critic 绕模型自轴复核，或改用奇数网格）
- `sdf_mesh` 的网格是**连续曲面**（Surface Nets 重建），非方块体素——体积与包围盒≈体素模型但有平滑圆角；薄壁/小特征分辨率过低可能闭合不上内壳。
- 分辨率越高三角越多越平滑；在 viewer 切"平滑网格"模式可拖分辨率滑杆交互探索。
- ⚠️ **平滑网格最小厚度**：要求模型存在 2×2×2 全实心胞块（节点=8 邻胞 SDF 平均，须严格为负）。1×1 线材/单层薄片在任何分辨率与 smooth 下都无面（实测 smooth 1-2 也无效）；**其他部分有面时薄特征被静默丢弃**——导出后对比体积。方块导出（export glb）无此限制。
- `sdf_mesh` **体积精度与 res/smooth 相关**：Surface Nets 体积 ≈ 体素体积（smooth=0 实测 ~96-99%，误差来自角/棱圆角）；**smooth 平滑有固有收缩**——blur 等价于对占用场低通再取零水平面，凸角/棱按平均曲率内收，分辨率越低、特征越小、smooth 越大收缩越显著（实测 8³ 盒 res=24：smooth=0 → -4%，smooth=2 → -21%）。用体积做「薄特征是否丢失」的判据时，务必与**同 res/smooth 的基准**对比，或直接用 smooth=0；模型贴世界网格边缘不影响体积（界外按空气处理，0.1.2 起）。

## 实时 Viewer（可选）

```bash
$VF serve /tmp/model.voxel.json   # http://127.0.0.1:4173，SSE 实时跟随每次工具调用；首次加载按模型 bbox 自动取景，后续编辑保持相机
```

工具栏「导出 GLB」按钮：按当前视图导出——体素模式=方块 GLB（顶点色），平滑网格模式=当前分辨率/平滑度的 GLB（自动带调色板图集贴图+UV）。也可直接 GET `/export.glb?mode=voxel|mesh&res=N&smooth=N&texture=0|1`。
