## 一、实测基线（本机 M 系列 / Node 24，dist 逐段计时）

| 场景 | SDF 段 | 网格化段 | 合计 | SDF 占比 |
|---|---|---|---|---|
| tank100 128³, res=128（默认） | 2.28–2.44s | 0.19–0.24s | ≈2.5s | **~91%** |
| tank100 128³, res=64 | 2.44s | 0.06s | ≈2.5s | 98% |
| T34 256³, res=256（默认） | 23.3s | 1.90s | ≈25s | **~92%** |
| T34 256³, res=128 | 24.6s | 0.28s | ≈25s | 99% |

- 吞吐仅 ~37M cell-updates/s（Float64 累加 + 逐邻居边界检查 + 分支判向）。
- 256³ 峰值 RSS **≈1.15GB**（occ Uint8 + empty/solid 双掩码 + 两块 Float64 距离场 + Float32 输出，全部满网格分配）。
- 颜色采样（`sampleVoxelColor`，string-key Map + r≤2 邻域搜索）占网格化段 ~22%（240ms→187ms，128³）。
- **bbox 白算**：tank100 bbox 仅占整网格 24.6%，T34 仅 22.6%——SDF 在 3/4 以上的纯空气区全功率空跑。

## 二、瓶颈定位

1. `computeSignedDistance`：全网格 **两次** 8SSEDT（26 邻居 × 前向/后向 × 2 个掩码），O(52N) 且与体素数无关——网格化只占 1~9%，**SDF 是唯一主瓶颈**。
2. 满网格密集场：内存与耗时都吃整 grid.size，而不是模型 bbox 或表面附近。
3. `sampleVoxelColor` 走 `grid.get`（每次 `${x},${y},${z}` 字符串分配 + Map 探测，最坏 1+124 次探针/顶点）。
4. 网格规整性：naive Surface Nets 顶点 = cell 边交点**等权平均** → 平坦区起波浪、quad 对角线全部同向（方向性伪影）、体素盒子棱角被系统性圆化；`boxBlur` 平滑还会均匀收缩薄壁。

## 三、提效路线

### P0 纯算法修复（不动架构，输出与现状等价/近等价，预期合计 8–15×）

1. **裁剪到模型 bbox（pad 1）再算 SDF**：`grid.bounds()` 现成未用。场坐标加 worldOffset，输出几何不变。≈4×（23%→100% 利用率）。
2. **两次 EDT 合并为一次（真实 chamfer 语义下精确等价；实现级以 max|Δ|≤1/3 回归闸门验收，见附录）**：种子 = 界面胞（26 邻域内存在异相邻居），seed 值 = 到异相邻居的最小步权；传播后 solid 取 −d、air 取 +d。省整整一次 EDT → 2×。
3. **累加器 Float64 → Uint16**：3-4-5 权重和恒为整数，max ≈ 3·Σ轴长 ≈ 2304 ≪ 65535。内存带宽减半，缓存命中改善 ≈1.3–1.8×。
4. **颜色改密集索引场**：建 occ 时顺手写 `paletteIdx: Uint8Array`（同一遍循环），`colorAt` = O(1) 类型数组读 + 调色板 LUT，零字符串分配；r≤2 邻域兜底仅保留给边界顶点。网格化段 ~22% → ~0。
5. **res ≥ maxAxis 时跳过三线性**：cs=1 时 nodeField 可直接平移拷贝 `field.data`；顶点法线从 nodeField 中心差分取（数据已采样在手），替代现 gradAt 的 6 次三线性重采样。
6. **活跃 cell 列表**：nodeField 采样一遍时同步标记 sign-change cell，三条边循环只扫活跃集（省 3 次全网格冗余 inside 检查）。

预期：256³ ≈25s → **2–3s**；128³ ≈2.5s → **≈0.3s**；内存峰值 1.15GB → ~150MB（bbox + Uint16）。

### P1 结构性提速（输出近等价，再 2–8×）

7. **窄带 SDF（band k≈3–6）**：只松弛界面附近 ±k，远场 clamp 到 ±k。网格化只需要零穿越面，k≥3 时 3-4-5 两扫描路径不越带（实践中零误差，可加一次与全场结果的最大误差回归验证）。内存 O(表面×k) ≪ O(N)：256³ 峰值可 <30MB。
8. **worker_threads 并行**：EDT 按行/块分片 + 归并，或整体挪入 worker 池；Surface Nets 天然按 cell 并行。M 系列 4–8×。
9. **viewer 交互增量重算**：编辑后只重算局部区域的窄带 SDF + 局部 Surface Nets，配合分辨率 LOD（r256/r128/r64 预生成），滑杆拖动零卡顿。

### P2 平滑语义修正（顺带）

10. `boxBlur` 边界处 cnt 变化造成边界偏置 → 补零/复制填充统一窗口；`smooth` 改 **Taubin λ|μ** 双步平滑替代逐次 box blur，避免薄壁收缩与细节磨平。

## 四、网格规整路线（体素→专业模型的核心增量）

### 路线 B：平面/曲面混合（体素模型特化，性价比最高，推荐先做）

- 判定：某 cell 的邻域面法线全部轴对齐且共面（体素占用差分直接给出**精确** Hermite 法线，免费）→ 直接输出**轴对齐 quad**（顶点=体素格点，零误差、完全规整）。
- 仅在曲率区（球面、圆柱端帽、圆角、斜面）保留 Surface Nets/DC 平滑。
- 平面区可再接 **greedy 合并**（同色共面大 quad）：三角形数再降 5–20×。
- 效果：坦克 hull、建筑这类"盒子为主"的模型，网格与体素网格严格对齐、锐利、规整；有机部件保持平滑。与现 pipeline 兼容（只在顶点放置与 quad 输出处分支）。

### 路线 A：Dual Contouring + QEF（锐利特征的标准解，作第二阶段）

- 每条穿越边存交点 t 与法线 n（体素占用差分或 SDF 梯度），每 surface cell 解 3×3 QEF（几十 flop）min Σ(n·(x−p))²。
- 平坦 cell 顶点收敛到平面 → quad 共面；棱/角保持锐利，比 naive 平均规整一档。
- 必须 clamp 顶点在 cell 内（防 QEF 外溢）；薄壁/小特征防非流形（退回平均或 manifold-DC）。

### 路线 C：greedy meshing 导出档（若"规整"=方块美学 + 极省三角形）

- 现有 `export glb`（buildMesh）每暴露面 2 tri；greedy 合并同色共面面 → 轴对齐大 quad，单遍 O(N)，**完全不需要 SDF**——比整条 sdf 管线快两个数量级，三角形通常降 10–50×。
- 适合低模/游戏资产交付；与 B 不互斥，作为 export 的 `format:"glb-blocky"` 档位即可。

### 路线 D：专业收尾（后处理与导出档位）

- QEM 抽稀 + LOD 链（100%/50%/25%）；
- KHR_mesh_quantization / EXT_meshopt_compression 压缩 GLB；
- 顶点色 → 材质图集纹理（材质边界干净、顶点属性更瘦）；平面区用面法线（flat shading 更规整）。

## 附：单次 EDT 等价性论证（P0-2，含语义一致性）

记相位 S(solid)/E(air)，chamfer 步权 step∈{1, 4/3, 5/3}（26 邻域，w/3 归一化）。界面 I = {c : 26 邻域含异相胞}，种子值 v(c) = min over 异相 26 邻 n of step(c→n)。单场传播后 solid 取 −R、air 取 +R。目标：solid i 处 R(i)=d_empty(i)（air 侧对称）。

**下界（任一种子路径贡献 ≥ 真值，两 case 封死低估）**：
- solid 界面种子 c，v(c)=step(c→e_c)（e_c 为最近空 26 邻）：拼接 e_c→c→P→i 为合法 chamfer 路径，贡献 = v(c)+cost(P) = 整路 cost ≥ d(i,e_c) ≥ d_empty(i)。
- 空相种子 c：取路径 P 上最后一个空胞 x（必存在，c∈E、i∈S），后缀 x→i 权 ≤ cost(P) ≤ v(c)+cost(P)，且 x∈E ⇒ d_empty(i) ≤ d(i,x) ≤ 后缀权。（与 v(c) 具体值无关，v≥0 即可）

**上界（存在达到真值的种子路径）**：取 i 的最近空胞 e* 及最优路径，取其上最后一个空胞 p_m；则 p_{m+1} 为 solid 界面胞（若 p_{m+1}∈E 则它比 e* 更近，矛盾），v(p_{m+1}) ≤ step(p_{m+1}↔p_m)，suffix 权 ≤ W − cost(prefix) ≤ W − step(p_{m+1}↔p_m) ⇒ 贡献 ≤ W = d_empty(i)。i 自身即界面胞时 v(i)=d_empty(i) 直接成立。∎

**语义一致性三条（实现/验收约束）**：
1. **界面判定必须 26 邻域**（与 chamfer 模板同 stencil）。若用 6 邻域：纯对角接触的 solid 胞不成种子，只能靠远端种子传播 → 距离被高估 → 表面外凸/破面。反例：单胞仅对角方向接触空相。
2. **"精确等价"仅在真实 chamfer 距离语义下成立**。8SSEDT 双扫描在 3D 是 3-4-5 的近似（2D 3-4 才有精确性定理），两个版本的扫描路径集不同 ⇒ 实现级可能存在残差。**验收回归闸门**：同一模型单次 vs 双次 EDT 逐 cell 比对，max|Δ| ≤ 1/3 voxel，且零穿越面渲染目检无差异；超限则回退双 EDT（保底：bbox 裁剪 + Uint16 + 窄带仍有 ~6–10×，P0-2 降级为可选优化），或改用优先队列 Dijkstra（O(N log N)，语义精确）。
3. **边界语义与现状一致**：不引入虚拟边界源（现状边界空胞本身就是 d_empty 的源），避免系统性半格偏移。薄壁/网格级细结构模型界面占比高，单次 EDT 收益退化为 ~1×（不会更慢）；实体内部占比越高收益越接近 2×。另：满网格无空相的退化输入两版本同样无定义，由现有"无面"守卫兜底。
